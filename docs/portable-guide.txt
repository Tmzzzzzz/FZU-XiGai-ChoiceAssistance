习概选择题 · 使用说明
========================

1. 双击「习概选择题.exe」即可开始，不需要安装 Python，也不需要联网。

2. 做题记录保存在本文件夹的 userdata\progress.json。
   - 备份：复制这个文件即可。
   - 清空：删除 userdata 文件夹，或在程序里点「重置全部进度」。

3. 换电脑 / 发给同学：把整个「习概选择题」文件夹复制过去就行，
   路径里有空格或中文都没关系。

4. 想换题库：替换 data\questions.json（保持原有字段结构）。

5. 如果双击没反应：查看 logs\error.log（首次出错才会生成），
   或右键「在终端中打开」后执行：
       .\习概选择题.exe
   报错信息会直接显示出来。

6. 极少数精简版系统若提示缺少 MSVCP140.dll，安装一次
   “Microsoft Visual C++ 2015-2022 运行库 (x64)” 即可；
   正常安装过常用软件的系统都已自带。

快捷键：A–E / 1–5 选择　Enter 提交或下一题　← → 翻页　R 打乱顺序
