记录两份源文件的比对结果、抽取规则、勘误与存疑项，便于复核与后续维护。

## 一、逐题比对结论

| 项目 | 结果 |
| --- | --- |
| PDF 解析题数 | 272 |
| DOCX 解析题数 | 272 |
| 题序与章节归属一致性 | 272 / 272 一一对应 |
| 答案一致率 | 272 / 272（无冲突） |
| 题干 + 选项文本差异 | 2 题（仅 DOCX 丢失选项标识，见下） |
| 重复题 | 1 组 |
| 最终入库 | 271 |

结论：两份文件内容同源，PDF 完整度更高，因此**以 PDF 为主数据源，DOCX 用于逐题校对**；DOCX 有一处整段丢失选项字母、一处丢失 A 选项标识，均由 PDF 补齐。

比对方法：按「章 → 题型 → 题号」对齐，规范化空白与标点后计算题干、选项文本相似度，并逐题比对答案字母；相似度低于 0.93 或答案不同即人工复核。

## 五、抽取与校验规则

抽取（`tools/build_bank.py`）：

1. 去掉 PDF 页眉页脚与页码，按「导论 / 第X章」切章，按「一、单选题 / 二、多选题」切题型。
2. 以「答案：X」行为题目分隔锚点，兼容题号缺失、答案与字母被折行拆开、选项与题干同行等情况。
3. 选项定位按 A→B→C→D 顺序推进，允许行首无分隔符（如“A政治建设”）与行内单空格分隔（如“A.消费 B.投资”）。
4. 规范化空白：合并 PDF 折行、去掉中文之间与数字/中文之间的多余空格、填空统一为「（　）」。

入库前强制校验（任一不满足即构建失败）：

- 题 id 唯一；章节 id 存在；
- 每题至少 4 个选项、选项字母不重复；
- 答案字母必须落在选项集合内；
- 单选恰 1 个答案、多选至少 2 个答案；
- 每题必须有解析，且知识点必须在所属章节登记；
- 全库题干去标点后不得重复；
- 知识点不得跨章重名、不得重复分配。

界面层加载时（`app/models.py`）再做一次轻量校验，保证手工编辑 JSON 出错时能给出明确报错。

## 六、解析说明

源文件不含解析。题库中的解析依据教材固定表述撰写，用于说明正确选项的依据或错误选项的问题，平均约 38 字；对易混淆项（如“四个全面”与“五位一体”、总体国家安全观的宗旨/根本/基础/依托）额外点明区分点。若与课堂讲义不一致，直接修改 `data/questions.json` 的 `explanation` 字段即可。
